## 二、核心功能

1. **打字测速**：从词库随机取 180 词（词库不足 180 时全量使用），contenteditable
   输入区逐词输入，空格/回车换词，60 秒倒计时结束后弹出成绩 Modal（词/分、字/分、准确率）。
2. **逐词实时校验**：`matchSourceAndTarget` 拟合匹配，前缀正确时把"当前词"裁剪成
   剩余后缀（渐进式高亮），出错词在已完成区以删除线标红。
3. **词库选择**：7 个内置分类 + 用户自定义词库，`import.meta.glob` 动态加载 JSON，
   localStorage 缓存；下拉受控渲染，自定义项支持行内删除（带确认）。
4. **自定义词库**：弹窗输入标题 + 纯英文文本，前端提取单词（小写、去重、保留连字符
   与撇号），以与内置词库一致的 `[[word, ""]]` 格式写入 localStorage；单词不足 180
   时自动复制整份扩充，保证单轮测试词量充足。确认按钮以 加号/对勾/叉号 三态图标
   反馈输入合法性。
5. **明暗主题**：跟随系统偏好 + 手动切换，持久化到 localStorage，同步 antd 主题算法
   与 Chart.js 配色（MutationObserver 监听 `data-theme`）。
6. **中英切换**：开关文字显示"点击后进入的状态"（当前中文 → 按钮显示 En），
   切换 i18n locale 与"是否显示中文释义"。

## 四、质量保障现状

1. **测试**：`pnpm check:all` 一键跑通 lint → typecheck → 单测 → 构建 → e2e。
   覆盖率全局阈值 60%（statements/lines，防劣化底线），当前全局 91%、`utils.ts` 98%。
2. **静态检查**：ESLint 在 vue3-essential 基础上叠加了 `no-explicit-any`、
   `consistent-type-imports`、`no-duplicate-imports`、`eqeqeq`、`curly`、
   空行规则（`padding-line-between-statements` 等）与 `vue/require-prop-types`
   等规则，`--max-warnings 0`，可通过 `pnpm lint:fix` 自动修复大部分违规。
3. **类型安全**：`tsconfig.app.json` 启用 `noUncheckedIndexedAccess`、
   `exactOptionalPropertyTypes`、`noImplicitReturns` 等（完整清单见 `docs/贡献指南.md`），
   组件已消除 `any` 与数组式 props。
4. **pre-commit**：lint-staged（eslint --fix + prettier）→ 全量单测 → 构建 →
   提交 dist，详见 `docs/贡献指南.md`。
